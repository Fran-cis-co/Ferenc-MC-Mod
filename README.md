# Francisco's Minecraft Mod
This project is just a minecraft mod which is a culmination of multiple topics of modding all under one project.   
This is probably not the most efficient way of setting this up, but I want my first mod to be under one repository.  
This repository will also include branches with different items such as ore, armor, food, etc.  
There will also be documentation of all the modded items including details on what they do and how to craft them.
This project will be titled "Ferenc's MC Mod".

# Silver  
For Monsters!  

I've implemented a custom ore titled Silver. While I did take inspiration from the real life ore Silver, I believe  
I did not do the best job in faithfully adapting it into Minecraft, so I took creative freedom in implementing it.  
Silver originally comes in raw form which can be smelted into silver ore. In terms of balancing, crafting armor or tools  
with this ore will have a power scale between iron and diamond (Spoilers, I will implement something for end-game).
